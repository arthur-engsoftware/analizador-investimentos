# Investment Analyzer

O **Investment Analyzer** é uma aplicação para organizar informações sobre investimentos e apoiar sua análise. Seu código-fonte está neste diretório.

## Começando

Consulte o `README.md` na raiz do repositório para instruções de instalação e execução. Verifique também os arquivos de configuração do projeto para identificar os comandos e requisitos atualizados.

## Desenvolvimento

- Siga as convenções já adotadas no projeto.
- Execute os testes disponíveis após realizar alterações.
- Mantenha as contribuições focadas e documente mudanças relevantes.

## Aviso

As análises fornecidas pela aplicação têm caráter informativo e não constituem recomendação financeira. Investimentos envolvem riscos; avalie sua situação antes de tomar decisões.
